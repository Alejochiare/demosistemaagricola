# Prompt profesional para recrear el sistema de control de lotes como un producto de nivel empresarial

Quiero que recrees este sistema como una aplicación web profesional, moderna y escalable, con la calidad visual y funcional de una plataforma real del sector agroindustrial. No lo hagas como una demo básica ni como una maqueta simple. Debe sentirse como un sistema serio, bien diseñado y listo para uso real.

## Objetivo
Crear una aplicación web premium en HTML, CSS y JavaScript puro para gestionar operaciones agrícolas de forma eficiente. El sistema debe incorporar la lógica del sistema original, pero transformada en una experiencia mucho más robusta, limpia y profesional.

## Tipo de producto esperado
Quiero que la IA lo genere como si fuera un sistema de gestión agrícola tipo SaaS, con interfaz moderna, estructura de producto real y experiencia de usuario cercana a plataformas del mercado.

## Módulos principales
El sistema debe incluir:

1. Dashboard ejecutivo
- Mostrar métricas clave como número de lotes, siembras activas, fumigaciones registradas, cosechas realizadas y notas pendientes
- Mostrar tarjetas de resumen con gráficos simples o indicadores visuales
- Incluir una sección de alertas o estado general del sistema
- Mostrar resúmenes por lote o por cultivo

2. Gestión de lotes
- Crear, editar, eliminar y listar lotes
- Campos: nombre, tamaño, ubicación, estado, observaciones opcionales
- Mostrar lotes en tarjetas elegantes o tabla organizada
- Incluir filtros y búsqueda por nombre o ubicación

3. Gestión de cultivos
- Crear, editar, eliminar y listar cultivos
- Campos: nombre del cultivo, tipo, descripción opcional
- Relacionar cada cultivo con registros posteriores de siembra y cosecha

4. Gestión de siembras
- Crear, editar, eliminar y listar siembras
- Campos: fecha, producción estimada, cantidad de semillas, superficie sembrada, destino, lote, cultivo
- Permitir filtros por lote, cultivo y fecha
- Mostrar información ordenada y fácil de leer

5. Gestión de fumigaciones
- Crear, editar, eliminar y listar fumigaciones
- Campos: fecha, producto, dosis, aplicador, lote, motivo
- Permitir filtros por lote, aplicador y fecha
- Mostrar una vista clara y profesional del historial de fumigaciones

6. Gestión de cosechas
- Crear, editar, eliminar y listar cosechas
- Campos: fecha, producción real, lote, cultivo
- Permitir filtros por lote, cultivo y rango de fechas
- Mostrar resultados organizados como un historial operativo

7. Gestión de notas o extras por lote
- Crear, editar, eliminar y listar notas relacionadas a un lote
- Campos: título, descripción, fecha, prioridad opcional
- Mostrar notas como un bloque de seguimiento operativo

## Requisitos de diseño
- Diseño visual premium, limpio y moderno
- Paleta de colores agrícola profesional: verdes oscuros, verdes claros, beige, arena, blanco y azul suave
- Interfaz responsive para móvil, tablet y escritorio
- Uso de tarjetas, tablas, formularios, badges, botones y jerarquía visual clara
- Animaciones suaves, hover elegante, transiciones fluidas y microinteracciones profesionales
- Incluir estados vacíos, mensajes de éxito/error, validaciones visuales y feedback al usuario
- Debe verse como una herramienta seria y preparada para producción

## Requisitos funcionales avanzados
- Implementar navegación SPA sin recargar toda la página
- Crear un menú lateral o superior elegante y usable
- Organizar el código de forma modular y profesional
- Guardar datos en localStorage para persistencia sin backend
- Permitir agregar, editar, eliminar y filtrar registros sin romper la interfaz
- Incluir búsqueda, ordenamiento y vistas bien estructuradas
- Añadir modo oscuro opcional
- Incluir datos iniciales realistas para demostrar la experiencia del sistema

## Requisitos técnicos de alto nivel
Estructura de carpetas recomendada:
- index.html
- css/styles.css
- js/app.js
- js/data.js
- js/ui.js
- assets/ para íconos o imágenes opcionales

Tecnologías:
- HTML5 semántico
- CSS moderno con variables, grid, flexbox y diseño responsive
- JavaScript puro sin frameworks
- Arquitectura modular para facilitar futuras integraciones con backend

## Estilo de implementación
Hazlo como un desarrollador frontend senior y un diseñador de producto. Prioriza:
- calidad visual superior
- organización de código limpia
- escalabilidad futura
- experiencia de usuario premium
- consistencia visual y lógica de negocio entendible
- interfaz que se vea seria, confiable y profesional

## Instrucciones especiales para la IA generadora
- No generes una versión simple o básica
- No uses estilos genéricos o poco pulidos
- No dejes componentes incompletos o difíciles de usar
- Debe sentirse como un sistema real de gestión agrícola, listo para presentarlo como un producto profesional
- Si es posible, incluye secciones como resumen ejecutivo, panel de operaciones y gestión de registros con apariencia de software empresarial

## Resultado esperado
Una aplicación web completa, visualmente atractiva, funcional, moderna y profesional, lista para abrirse en el navegador y presentar como un sistema de gestión agrícola de nivel empresarial.
